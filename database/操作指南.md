# 云数据库操作指南

## 第一步：创建数据库集合

在微信开发者工具中：

1. 点击 **云开发** 按钮（顶部工具栏）
2. 进入 **数据库** 标签页
3. 点击 **+添加集合**，创建以下3个集合：

| 集合名称 | 用途 |
|---------|------|
| `users` | 存储用户信息、收藏列表、打卡天数 |
| `palettes` | 存储色板数据 |
| `checkins` | 存储打卡记录 |

## 第二步：导入初始数据

1. 点击 `palettes` 集合
2. 点击 **导入** 按钮
3. 选择文件：`database/palettes.json`
4. 确认导入

**注意：** 如果导入报错，可以手动逐条添加，或在开发者工具中运行以下代码初始化：

```javascript
// 在任意页面的onLoad中临时运行，然后删除
const db = wx.cloud.database()
const palettes = [
  { name: '初春晨雾', colors: ['#E8B4B8','#F0CECE','#C9B8E8','#F9F0E0','#D4C4A8'], emotionTag: '温柔', likeCount: 128 },
  { name: '暮光晚橙', colors: ['#F18F43','#F5A660','#D5DD5E','#E8D080','#F0C860'], emotionTag: '活力', likeCount: 204 },
  { name: '苔原初绿', colors: ['#94B276','#A8C488','#7A9660','#B4D090','#C8DCA8'], emotionTag: '沉静', likeCount: 156 },
  { name: '烟雨江南', colors: ['#9B8EA8','#7A6880','#B8AABF','#6A5870','#C8C0D0'], emotionTag: '忧郁', likeCount: 118 }
]
palettes.forEach(p => db.collection('palettes').add({ data: p }))
```

## 第三步：设置数据库权限

1. 点击每个集合的 **权限设置**
2. 选择 **自定义安全规则**
3. 设置以下规则：

```json
{
  "read": true,
  "write": "doc._id == auth.openid"
}
```

或简化为：**所有用户可读，仅创建者可写**

## 第四步：测试功能

按以下流程测试：

1. **注册** → 输入用户名密码 → 检查 `users` 集合是否有新记录
2. **登录** → 用刚注册的账号登录
3. **首页** → 选择情绪 → 查看配色推荐
4. **收藏** → 点击色板收藏按钮 → 检查 `users.favorites` 是否更新
5. **打卡** → 点击"今日情绪色打卡" → 检查 `checkins` 集合是否有记录
6. **我的页** → 查看打卡日历和收藏列表

## 常见问题

### Q: 数据库查询返回空数组？
A: 检查集合是否已创建并导入数据；检查权限设置是否允许读取

### Q: 收藏/打卡操作失败？
A: 确保已登录（非游客模式）；检查数据库权限是否允许写入

### Q: 提示"云开发未初始化"？
A: 确保 `app.js` 中的 `wx.cloud.init()` 在 `onLaunch` 中执行
